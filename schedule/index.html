Comment obtenir mon Client ID ?
  1. Connectez-vous sur dev.twitch.tv/console/apps
  2. Cliquez sur "Register Your Application"
  3. Dans OAuth Redirect URLs, collez l'URL affichée ci-dessus (le bouton la copie)
  4. Catégorie : Website Integration — Type : Public
  5. Copiez le Client ID généré et collez-le dans le champ ci-dessus
